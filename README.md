This project aimed to create a portfolio website to display Art Pieces, and Code Projects in a stylistic and user friendly way. The user is able to view a Art and Code via tabs that match the name.

Behind the scenes this portfolio is managed as a CMS(Content Management System). I'm able to login as an admin and manipulate or add the content available. Such that I could use this website to advertise myself to potential employers. This project will further be improved throughout future years.
To view my content simply, from this simply pull it down and run in VSCode or an IDE of your choice, then navigate between the tabs. Eventually this will most likely become it's own independently hosted website requiring no such downloads.
